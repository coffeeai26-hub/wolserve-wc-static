Wolserve Western Cape — clean static site

Files included:
- index.html
- about.html
- services.html
- newsletter.html
- contact.html
- styles.css
- scripts.js
- images/ (placeholders)

Usage:
1) Download or clone this repository.
2) Open index.html in a browser (double-click). No server required.
3) Replace images/Picture 1.png ... Picture 14.png with your real images (use exact filenames).

Newsletters: list issues in newsletters/newsletters.json (admin/upload-newsletter.php adds them
automatically on a PHP host; static hosting needs the PDF + JSON entry committed instead).
Masonry photos: put files in images/masonry/ and list them in images/masonry/gallery.json.
